# Historical evidence manifests

This directory tracks small audit reports, manifests and qualification summaries.
Their digests describe the original recorded packages and source/binary versions.
The experiment files are retained as historical records rather than rewritten to
describe the current checkout.

Raw archives, generated PTX, logs, build outputs and publication working files
remain local and are excluded from Git. A checksum or a local path is not a
hosted download, and a fresh checkout cannot verify omitted payloads without
obtaining those artifacts separately. See [artifact availability](../README.md).

# Historical benchmark drivers

These small driver scripts and baseline source excerpts document earlier
measurements. They are preserved historical versions, not a second maintained
implementation of the current benchmark. Some refer to local build outputs or
source snapshots that are intentionally excluded from Git.

Compressed full-source snapshots remain local; their hashes are recorded in the
reports and manifests. See [artifact availability](../README.md). Use the current
tools under `integrations/transformer_bench/` and the
[benchmark instructions](../../transformer-training-performance.md) for new runs.
